# /memspell

## Syntax
<!--cmd-syntax-start-->
```eqcommand
/memspell <gem> [ "<spellname>" | <spellID> ]
```
<!--cmd-syntax-end-->

## Description
<!--cmd-desc-start-->
Attempts to memorize "_spellname_" or _spellID_ into gem _gem_. Any _spellname_ with more than one word must be surrounded by quotes.
<!--cmd-desc-end-->
## Examples

`/memspell 1 "Shallow Breath"`

`/memspell 1 64092`
