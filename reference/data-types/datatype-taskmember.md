# `taskmember`

<!--dt-desc-start-->
Describes a member in your current task
<!--dt-desc-end-->
## Members
<!--dt-members-start-->
/// member | int Index
Returns task index for member (i.e., 1-6)
///

/// member | bool Leader
Returns true if member is leader
///

/// member | string Name
Returns name of the mamber
///
